算法原理与使用须知

一句话原理

把水印图打散成噪声状的图案，直接加到位图的频域（FFT 结果）上，再逆变换回空间域。因为改的是频域的一个极小的量，画面看不出差别；解码时用「原图频谱」和「含水印图频谱」相减，就能把那个图案捞回来。

完整流程（对齐 chishaxie/BlindWaterMark）

  1. 取一块 (高/2, 宽) 的空画布，把水印贴到左上角，得到 hwm2；
  2. 用种子 seed 驱动一个伪随机洗牌，生成两个置换 m（长度 高/2）和 n（长度 宽）；
  3. 令 hwm[i][j] = hwm2[m[i]][n[j]] —— 水印被彻底打散，看起来像噪声；
  4. 把 hwm 以 180° 翻转的方式镜像铺满整张画布，得到 rwm；
  5. img_wm = real( ifft2( fft2(img) + alpha × rwm ) ) —— 水印叠加完成。

分离就是反向：rwm = real( (fft2(img_wm) − fft2(img)) / alpha )，再按 m、n 把位置还原回去。

关键约束

  • 必须提供原图。这是加法式频域盲水印的固有限制：分离本质上是做频谱差分，没有原图就没有基准。原图必须是加水印之前的那一张原始文件，重新保存过（哪怕只是重新编码）都会导致解不出来。
  • 水印尺寸受限：高度必须小于载体图高度的一半，宽度必须小于载体图宽度。
  • 用 PNG 保存。JPEG 是有损压缩，会破坏频域里的水印；本工具下载的一律为无损 PNG。
  • 不能缩放、裁剪、旋转含水印图，这些操作会直接毁掉水印。

为什么分离结果有条纹和噪点

两个原因，都来自算法本身：

  • 原作用 rwm[H-1-i][W-1-j] 做镜像，而 DFT 意义上的对称是 (H-i) mod H，两者相差 1 个像素。这导致逆变换时约一半能量无法还原，表现为沿对角线方向 1 像素的双影，以及图片首行首列只有一半亮度。
  • 解码时又用 np.uint8() 截断取整，量化误差被放大成可见的颗粒。

本工具保留了这一行为以保证与 Python 版互解；如果你只在本工具内闭环使用，把「变换模式」切到高质量可以显著改善画质和分离效果。

「兼容原作」与「高质量」两种模式的区别

模式做了什么特点
兼容原作 复刻 np.fft.fft2(img) 对 (H,W,3) 数组的默认行为 —— 它的变换轴其实是「宽度轴 + 通道轴」，等价于逐行做 (宽, 3) 的二维变换 可与 Python 版互相解出；检测判据极灵敏；但图像改动略大（PSNR ≈ 41 dB）
高质量 每个颜色通道各自做一次真正的空间二维 FFT 改动极小、几乎完全无感（PSNR ≈ 58 dB）；但只有本工具能解，Python 版解不出来

上面三个面板藏的是图片，而且提取必须提供原图。隐写面板换了一条完全不同的技术路线—— 藏的是数据，而且不需要原图。

引擎藏什么容量（1024×1024）免原图抗压缩
FFT 加法式（前三个面板）图片水印大否弱
DWT-DCT-SVD（鲁棒模式）文字 / 短数据约 6 KB是较强
LSB（大容量模式）任意文件约 393 KB是无

鲁棒模式为什么不需要原图

它对图像做一级 Haar 小波分解取低频子带（LL），分成 4×4 块，每块做 DCT， 再对系数矩阵做 SVD，然后用「量化索引调制」把 1 个 bit 写进最大奇异值 s0：

q = floor(s0 / delta)　→　q' = 2*floor(q/2) + bit　→　s0' = (q' + 0.5) * delta

格点序号的奇偶本身携带了 bit，提取时把 s0 除回去取整就能读出来， 根本不需要知道原始 s0。又因为奇异值对图像扰动不敏感， 所以图片经过一定程度的压缩后仍能原样读回（实测 ±6 级像素抖动依然可解）。

代价：容量小（约 (高/8)×(宽/8)×3 个 bit），而且对缩放和裁剪敏感—— DWT 的分块位置一旦错开就提取失败。所以不要改尺寸。

大容量模式（LSB）

直接把数据按位写进像素最低有效位。容量是鲁棒模式的上百倍，同样免原图，画质几乎无损（PSNR 通常 60 dB 以上）。 但它没有任何鲁棒性：只要图片被 JPEG 压缩、缩放、截图或旋转，数据就彻底没了。 用它就必须原样保存与传递 PNG。

密码用于打散写入位置，提取时必须填一致。密码不对会因容器头部校验失败而直接报「没有提取到数据」。

关于「检测」

精确检测用的是一个很干净的判据：水印只叠加在频域的实部上，所以「含水印图频谱 − 原图频谱」在理想情况下是纯实数的。若图中并没有水印，这个差值就只剩量化/压缩噪声，实部与虚部能量相当。于是：

  • √(E实部 / E虚部) ≈ 1 —— 没有水印；
  • √(E实部 / E虚部) ≫ 1 —— 存在水印（实测可到 10 以上，而对照图只有 1.5 左右）。

不给原图时的「盲检」只是看径向功率谱在高频有没有异常的平坦"地板"，会被图像本身的噪声和纹理干扰，不能作为判定依据，仅作参考。

与 Python 原作互通

本工具的随机数发生器完整复刻了 CPython 的 MT19937（seed / getrandbits / _randbelow / shuffle），FFT 也复刻了 numpy 的变换轴选择。在「兼容原作」模式下，网页的合成结果可以直接用 bwmforpy3.py decode 解出，反之亦然（需保证 seed、alpha 一致，且图片用 PNG 无损传递）。
